# toolsy.online — Geo Mukkath's portfolio

Official website of **Geo Mukkath — AI-Native Product Manager**, built with Next.js (App Router), React 19, and Tailwind CSS v4.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

## SEO

- Metadata (title, description, keywords, canonical, robots) in `src/app/layout.tsx`
- JSON-LD structured data: `ProfilePage`, `Person`, `WebSite`, `WebApplication` (QuickShapes), `FAQPage`
- Dynamic Open Graph image at `/opengraph-image` (name-forward, blueprint style)
- Favicon + Apple touch icon via `src/app/icon.tsx` and `src/app/apple-icon.tsx`
- Web manifest at `/manifest.webmanifest` via `src/app/manifest.ts`
- `sitemap.xml` and `robots.txt` generated by `src/app/sitemap.ts` and `src/app/robots.ts`

## GEO (Generative Engine Optimization)

- `robots.txt` explicitly allows AI crawlers: GPTBot, OAI-SearchBot, PerplexityBot, ClaudeBot, Google-Extended, Applebot, and more
- `/llms.txt` serves a concise, quotable brief about Geo Mukkath for LLMs (via `src/app/llms.txt/route.ts`)

## Launch checklist (do once, after deploying)

1. **Google Search Console** — [search.google.com/search-console](https://search.google.com/search-console): verify `toolsy.online`, then submit the sitemap `https://toolsy.online/sitemap.xml`. Request indexing for the homepage.
2. **Bing Webmaster Tools** — [bing.com/webmasters](https://www.bing.com/webmasters): import from Search Console, submit sitemap. Powers Yahoo/DuckDuckGo and ChatGPT's search index.
3. **LinkedIn** — add `https://toolsy.online` as a website on the LinkedIn profile, so `sameAs` links are bidirectional. This is the single most effective entity-linking step for name searches.
4. **Verify structured data** — paste the deployed URL into [Google Rich Results Test](https://search.google.com/test/rich-results) and [validator.schema.org](https://validator.schema.org).
5. **Monitor** — after 1–2 weeks, search `Geo Mukkath` on Google, Bing, ChatGPT, and Perplexity to see whether the site surfaces; iterate on the FAQ content with real questions people ask.
